# Single-File-C--Scripts

## Overview
These are scripts that I created in VS Code, meant to be run within the terminal.

### Contact Book
#### Overview
 This is a contact book program I created that you can use to organize your contacts.
#### Features
- You can store contacts with a name, phone number, and address
- You can access existing contacts and their information
- You can delete contacts
#### Future Improvements
- Have it save your data when you stop and start the program

[Contact Book Demo Vid](https://youtu.be/XWaN1hi9yBY)

### Space Game (Program.cs)
#### Overview
 This is a simple space exploration game that I created
#### Features
- You can travel to different planets
- You can search for unique artifacts on each planet with different rarities
- You can sell artifacts to gain credits, which you use to search
- Collect the rarest artifact from each planet within the solar system to beat the game.
#### Future Improvements
- Add more planets and more artifacts
#### Demo Video

[Contact Book Demo Vid](https://youtu.be/XzyHxM-FFps)

### Number Guessing Game
#### Overview
 This is a game that I created where you have to guess a random number
#### Features
- You can guess numbers, and the program will tell you if the answer is higher or lower
- You can play as many times as you want
#### Future Improvements
- Add more games related to numbers
- Create a system that changes the difficulty (decreasing the range of possible numbers or adding a Hot/Cold system to help with getting closer)
